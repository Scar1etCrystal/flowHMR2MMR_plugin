# 方向说明（给使用插件的人）

这份说明只讲一件事：**你怎么把"我看到的朝向"准确地交给 agent**，以及你自己怎么摆、怎么检查那些用来表达方向的物体。

参数细节见 `PARAMETERS.md`；agent 侧的工具用法在仓库的 `docs/工具手册_agent.md`，不属于本说明的范围。

## 1. 为什么需要它

插件里的自动修复是在后台 Blender 里改骨骼的：它**没有视口**，只能靠数字判断方向对不对。而**你看到的是模型网格**。这两者过去会对不上：

- 手掌朝哪——按手指几何推出来的方向，和你在视口里看到的掌心，弯指时能差几十度；
- 说"朝前"——如果按世界的 −Y 去理解，角色一转身就完全错了；
- 说"朝左"——如果不区分角色自己的左和画面上的左，正面镜头下正好是反的。

现在这几件事都对齐了：

- 掌心、脚底这类部位改成按**模型网格**标定（掌心皮肤相对手骨是刚性的，实测散布 ≤1.5°）；
- "朝前 / 朝左"这类说法改成**方向词**，逐帧跟着角色算，不再写死世界坐标；
- 你还可以直接摆一支箭头，把方向**指**出来，工具会以你的箭头为准。

## 2. 四种方向物体，别混

| 名字 | 是什么 | 谁建 | 怎么理解 |
|---|---|---|---|
| `MCD_palm.L/R`、`MCD_sole.L/R`、`MCD_knee.L/R`、`MCD_elbow.L/R`、`MCD_face`、`MCD_chest`、`MCD_pelvis` | 长期有效的**部位标定箭头** | agent 的 `markers` 建，或你自己绑好后让 agent 收编 | 箭头指向 = 你看到的那个部位的朝向 |
| `mcd_dir_*` | 某一条修复的**方向箭头** | 面板按钮 | "让这个部位**平行于**这支箭头" |
| `mcd_aim_*` | 某一条修复的**指向点**（小球） | 面板按钮 | "让这个部位**指向**这个小球的位置" |
| `MCD_bake_*` | 逐帧打关键帧的**观察箭头** | agent 的 `markers bake` | 只显示当帧方向，**不是**定义，别拿它当 `MCD_*` 用 |

两条通用规则：

- 空物体的**局部 +Z 轴**就是箭头显示的方向（Blender 的 Single Arrow 显示的就是 +Z）；
- `MCD_*` 标定箭头靠**骨骼父级**跟随模型，你自己**不要**给它加关键帧。

## 3. 自己手动绑一支 `MCD_*` 标定箭头

面板里目前没有建标定箭头的按钮（这一侧由 agent 的 `markers` 建）。如果你想自己绑，照下面做。

### 3.1 先摆一支箭头

1. 在模型上找到你要表达的部位（比如左手掌心）。
2. 到一帧能看清这个部位朝向的帧（**任意一帧都行**，绑好之后整段都会跟着对）。
3. `Shift+A` → `Empty` → `Plain Axes`，命名成 `MCD_palm.L` 这样的名字。
4. 物体属性 → `Object Data Properties`（绿色小箭头图标）→ 把 `Empty Display` 改成 **`Single Arrow`**。
5. 摆到皮肤**外侧一点**，别埋进网格里，不然你看不见它。

### 3.2 绑到骨骼

1. 先选中这支 Empty，再 `Shift` 选中骨架对象（网格真正跟着动的那个 MMD 骨架）。
2. 进入 **Pose Mode**，选中目标骨骼（见下表）。
3. `Ctrl+P` → **`Bone`**。

绑好之后箭头就固定跟着那根骨动——**在一个帧上对准，整段动作都跟着对**。

### 3.3 绑到哪根骨

| 箭头 | 绑到（MMD 骨骼） | 箭头指向 |
|---|---|---|
| `MCD_palm.L/R` | `手首.L/R` | 你看到的**掌心**朝向 |
| `MCD_sole.L/R` | `足首.L/R` | 你看到的**脚底**（鞋底）法线 |
| `MCD_knee.L/R` | `ひざD.L/R` | **膝盖骨**凸出的方向（不是大腿朝向） |
| `MCD_elbow.L/R` | `ひじ.L/R` | **肘尖**方向（鹰嘴；不是肘窝——肘窝是它的反方向） |
| `MCD_face` | `頭` | 脸朝哪 |
| `MCD_chest` | `上半身2` | 胸口朝哪 |
| `MCD_pelvis` | `下半身` | 骨盆朝哪 |

腿上的 `ひざD` 是网格权重真正在的那根骨（和 `ひざ` 只差 ≤1.1°），所以绑它最稳。

### 3.4 绑完自己检查

- 拖时间轴，箭头应该**一直贴着那个部位**跟着转。只在某几帧贴着、一动就掉队，多半是绑错了骨或绑到了别的部位。
- 箭头**不要**有自己的关键帧、驱动或约束。带了就不算刚性定义，工具会拒绝读它（并告诉你怎么修）。
- **不要**用 `Child Of` 约束 + 顶点组的方式绑（会跟不住）。
- 用"顶点三角形"父级也可以，但三个顶点必须**都是那根骨权重 1.0** 的，而且要先绑再对准——比直接绑骨更容易点错顶点：有过实例是三个顶点全在右手上、箭头却摆在左手，两只手一起动时看着像在跟，左手自己一转就掉队。
- 掌心皮肤相对手骨是刚性的（实测散布 ≤1.5°），所以**绑骨就够了，不需要绑网格**。

### 3.5 让 agent 收编它

绑好、摆好之后，让 agent 执行 `markers adopt`，把名字、部位、左右报给它：

```
markers adopt {"name":"Empty.187","part":"palm","side":"L"}
```

它会检查父级骨、左右侧、有没有关键帧；合格就改名成 `MCD_palm.L`，并报出"与几何估计差多少度"。绑错侧、没骨骼父级、带关键帧的会被拒并说明原因。

如果箭头是 agent 用 `markers create` 建的，你可以**直接在视口里转动它**——不用重写任何东西，之后的探测就以你的朝向为准。

## 4. 单条修复的方向箭头 / 指向点

**3D 视口右侧栏 → `MoCap Doctor` → `Agent 协作`** 面板里，选中某一条修复后它下面会出现参数区；`方向物体` 那一行右边有两个小图标按钮：

- **＋**（箭头）：在 3D 游标处放一支 `mcd_dir_*` 箭头 → "让这个部位**平行于**这支箭头"。你把它转到想要的方向即可。
- **靶心**：在 3D 游标处放一个 `mcd_aim_*` 小球 → "让这个部位**指向**小球的位置"。

这两类物体**可以**打关键帧：给它们做动画，目标方向就逐帧跟着变（例如"手随着动作逐渐转向镜头"）。

⚠ 它们和 `MCD_palm.L` 那套**不是一回事**：`mcd_dir_*` / `mcd_aim_*` 只服务你正在调的那一条修复，`MCD_*` 是全局共用的部位定义。别把两者互相改名。

## 5. 方向词（说话时用这些）

| 你说 | 意思 |
|---|---|
| 朝前 / 朝后 | 角色**自己**的前后（躯干朝向，角色转身就跟着转） |
| 角色左 / 角色右 | 角色自己的左右（`.L` 那一侧 / `.R` 那一侧） |
| 朝镜头 | 从这个部位**指向镜头** |
| 背离镜头 | 背对镜头（= 镜头的视线方向） |
| 朝视口 | 朝你正在看的那个 3D 视口 |
| 画面左 / 画面右 / 画面上 / 画面下 | 屏幕上的左右上下 |
| 朝脚尖 | 同侧脚尖的方向（说"膝盖内扣 / 别内扣 / 朝外"其实就是这个） |
| 朝某个部位 | 例：`part:toe.L`（朝左脚尖）、`part:chest`（朝胸） |
| 朝上 / 朝下 | 世界的上下 |
| 朝某支箭头 | 那支箭头指的方向 |

三个容易搞错的地方：

1. **"角色的左"和"画面左"不是一回事**。正面镜头里角色的左在画面右边。要么明确说"角色的左"，要么直接说"画面左"。
2. **"朝前"不是固定的世界方向**。角色会转身，所以"前"是角色躯干当前的朝向。
3. **"朝镜头"是从那个部位指向镜头**，不是"相机的视线方向"（那反而是"背离镜头"）。

拿不准当前到底是什么样，可以让 agent 用 `conventions` / `orient_report` 描述这一帧，或者用 `render_view` 渲一张带方向的图给你看。

## 6. 一次完整的用法

1. **说帧段**：`532–556`（Blender 帧号）。
2. **说部位和角色左右**：`右手手心`。
3. **说你看到的**：`翻过来了，看不到掌心`。
4. **说想要的样子**：`手心朝镜头`。
5. **方向说不清就直接摆**：建一支 `MCD_palm.R` 箭头转到你想要的方向，告诉 agent 以箭头为准。
6. **让 agent 修**——一次一条，别一句话塞两件事。
7. **自己看**：在视口里对着视频帧看**实际网格**；用那条修复行首的**眼睛**图标单独关掉它，做修前/修后对比。
8. **还不对就带帧号再说**：`还是不对，F540 这只手应该手心朝前`。

修复写出来之后，条目下面的参数滑块（力度 / 阈值 / 帧范围 / 方向物体）可以**直接拖**，会自动重写，不用回来说。

## 7. 常见误区

- 把画面左当角色左（正面镜头下正好相反）。
- 把肘窝当肘尖——`MCD_elbow` 指的是**肘尖**；说"肘窝朝前"等于说肘尖朝后。
- 拿 `MCD_bake_*` 当长期定义（那是逐帧观察用的，长期定义应该用 `MCD_*`）。
- 给标定箭头打关键帧（`MCD_*` 必须是刚性的，只靠父级骨跟随）。
- 把箭头绑到网格顶点、绑到另一侧的骨，或用 `Child Of` 约束。
- 拿 `mcd_dir_*` 当 `MCD_palm.*` 用（前者只服务单条修复）。
- **只看数字不看网格**：工具报的度数对了、网格看着不对，就是还没修好——以你在视口里看到的为准。
